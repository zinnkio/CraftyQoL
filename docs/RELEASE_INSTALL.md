# CraftyQoL 0.18.2

Native Valheim crafting filters, recipe tracking and storage organisation.

**AI disclosure:** Created using OpenAI Codex, with maintainer-led in-game testing and feedback.

## Install

1. Install BepInExPack_Valheim 5.4.2351 for Valheim 1.0.21 and close the game.
2. Copy this archive's BepInEx folder into your Valheim folder, merging with the existing folder.
3. Confirm BepInEx/plugins/CraftyQoL/CraftyQoL.dll exists, then launch.

Client-side; no server installation required. Keep one plugin copy. If replacing the old Food Crafting UI development build, remove its DLL from the active plugins folder. Settings and saves do not need deletion.

Open inventory (usually Tab) to use tracker controls. Recipe pushpin/Ctrl+P pins recipes; Settings enables dragging/display pin. New tracker default: top centre. Search: Ctrl+F. Storage: Sort in the opened container.
