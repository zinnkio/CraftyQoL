# Changelog

## 0.18.2 - first public release

- Native food, Mead and equipment crafting filters across seven stations and inventory Craft.
- Search, sorting, favourites and discovery-gated biome filtering.
- Persistent multi-recipe tracker with combined carried-material totals and a top-centre default position.
- Explicit native storage Sort & Stack with conservative metadata-preserving consolidation.
- Hide future biome names and remove biome-classification text from recipe tooltips.
- Retain native crafting/Upgrade/Repair behaviour and existing saved custom tracker positions.

Earlier work is covered in the [development history](docs/DEVELOPMENT_HISTORY.md).
